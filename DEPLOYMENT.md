# Deploying

It's a static site, so any static host works.

## GitHub Pages
1. Push to `main` on https://github.com/kaverii11/resume-gamified
2. Repo **Settings → Pages → Source: Deploy from a branch → main / (root)**
3. It goes live at https://kaverii11.github.io/resume-gamified/ after a minute or two

## Vercel
```bash
npx vercel
```
